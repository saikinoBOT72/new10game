# スピンギア（SPIN GEAR）

ブレード・ラチェット・ビットの3パーツを組み替えて、物理演算で戦わせるコマバトルです。ブラウザだけで動きます（ビルド不要）。

## 遊び方

静的ファイルをそのまま配信して `index.html` を開きます。

```sh
npx http-server -p 8080 .
# → http://localhost:8080/
```

- **VS COM**: 自分の側（色のついた扇形）をタップしてスタート位置を決め、モンスト式に引っ張って離すとシュート（引いた向きの反対へ飛び、引くほど強い）。先に4点取った方の勝ち。
- **2人対戦**: P1 → P2 の順にシュート。
- **観戦**: COM どうしを戦わせて、組み合わせの相性を確かめられます。
- 時間は実際の 0.5 倍で進みます。「×1」ボタンで 2倍・4倍・0.5倍に切り替えられます。

## 物理演算（`src/physics.js`）

ゲーム用の性能値（攻撃力・持久力など）は持たず、形と物理量だけで計算します。

- **剛体**: 各コマは位置・姿勢（クォータニオン）・速度・角運動量を持つ3D剛体。重さ・重心・慣性テンソルは、パーツの形（極座標の輪郭を押し出した立体）と重量から積分して求めます。姿勢は角運動量を保存したまま中点法で積分するので、歳差運動や章動がそのまま出ます。
- **軸先と床**: 軸先は「半径 a の円板を半径 rr の球でなぞった形」。
  - 点の軸先（ボール・ニードル）は1点の接触で、転がりは撃力の摩擦、回転摩擦はヘルツ接触の接触円から計算します。
  - 平らな軸先は面全体がすべりながら床をこすります。床に対する傾きに応じて面の圧力が低い側へ偏り、各点のすべり摩擦を圧力で重み付けして足し合わせます。圧力が偏ると摩擦の合力が横向きに残り（線形の圧力分布なら (4/3)·μN·d/a）、これが斜面にいるコマを走らせます。ねじり摩擦もこの和から出ます。
- **コマどうし**: ブレード・ラチェット・ビットの輪郭そのもので当たりを判定し、接触剛性と減衰を持つ柔らかい接触として力で解きます。刃先が秒速20m以上ですれ違うので、剛体の撃力だと運動量の受け渡しが大きくなりすぎます。実際は接触面がたわむ約0.6msのあいだに刃先が滑って抜けます。反発係数は衝突速度が上がるほど下がります（塑性変形）。
- **壁・天井（透明カバー）**: 回転している輪郭の包絡線（最大半径の円）で当たります。刃先が壁の前を通り過ぎる周期（約3ms）と壁がたわんで応答する時間が同じくらいなので、壁から見ると刃の凹凸はならされます。
- **レール**: 床から立ち上がる固い段差。ビットのギアはラックとピニオンのように噛み合い、押し付けの強さによらずレールに沿った方向の力を伝えます。上限は半クラッチのトルクです。軸先とビットの下部もこの段差に当たります。奥でレールが内側へ曲がっていて、そこが射出ポイントになります。ポケットの左右では壁とレールがなめらかに外へ開いてポケットの口につながり（レールの外側の面が口の縁で壁に接する）、口の前ではレールが途切れています。
  - 右回転のコマは反時計回り、左回転のコマは時計回りにレールを走ります（ギアが段差を転がる向き）。
  - ダッシュの推進力はギアの高さ（重心より下）にかかるので、ジャイロ効果で内側へ傾きます。1回のダッシュで傾く角度は「得た運動量 × てこの長さ ÷ 角運動量」で、回転が速いほど小さくなります。
- **摩擦係数**: スタジアムは ABS 系の硬いプラスチック、プラスチックの軸先はポリアセタール（POM）を想定して 0.25、ゴムは 0.8。ボールの軸先は転がれないので（コマ全体が横に転がることになる）、動くときは床をすべります。中央から押し出されたコマがオーバーゾーンまで届くには秒速1.1m以上が要ります。
- **バンクシュート**: 進行方向の横へ倒して打ち出します。平らな軸先は低い側の縁で床をこすり、その摩擦 −μN·(ω×ê の向き) が進行方向を向くので、縁で転がるように走ります。
- **空気抵抗**: 回転方向を向いた輪郭の段差にかかる圧力抵抗と、表面の摩擦抵抗から計算します。
- **バースト**: ブレードとコア（ラチェット＋ビット）をロックでつながった別の物体とみなします。コアが回転を止める向きに叩かれると、ブレードは慣性で回り続けようとするので、ロックには「叩かれた角力積 × ブレードの慣性の割合」がかかります。ロックが保持できるトルクを超えた分が負荷として4段のゲージに溜まり、満タンで分解します。ゲージは時間で少しずつ戻りますが、越えた段の区切りより下には戻りません。ロックの強さはシャフトの太さで決まります。
- **刻み幅**: ふだんは 1/4000 秒。輪郭どうしや壁が近いときは、刃先が1歩で 0.7mm 以上動かないように自動で細かくします（最小 1/40000 秒）。

## 3つのパーツの役割

競技玩具研究所「ベイブレードＸ初弾構造レポート」による3層の役割分担を参考にしています。

| パーツ | 層 | 持っている物理量 | 効き方 |
|---|---|---|---|
| ブレード | 上層 | 輪郭・厚み・重量・金属部分の内径 | 慣性モーメント、当たったときの力の向き、空気抵抗。重いほど、ラチェットを叩かれたときにロックへ大きな力がかかる |
| ラチェット | 中層 | 輪郭（突起の数）・高さ・重量 | ブレードの高さ（どの帯で当たるか）。バーストの起点 |
| ビット | 下層 | 軸先の平面の半径・縁の丸み・素材・クラッチのトルク・シャフトの太さ | 床との摩擦、レールでの加速、ロックの強さ |

## ファイル構成

```
index.html        画面
style.css
src/parts.js      パーツデータ（物理量のみ）
src/shapes.js     パーツの輪郭（物理と描画で共通）
src/physics.js    物理演算・判定
src/render.js     Three.js による描画
src/audio.js      WebAudio の効果音
src/main.js       画面遷移・入力・ゲーム進行
tools/sim.mjs     ヘッドレスで対戦させて決着の内訳を確認（npm run sim）
vendor/           three.js r186（MIT）
```
