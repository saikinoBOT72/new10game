# スピンギア（SPIN GEAR）

ブレード・ラチェット・ビットの3パーツを組み替えて、物理演算で戦わせるコマバトルです。ブラウザだけで動きます（ビルド不要）。

## 遊び方

静的ファイルをそのまま配信して `index.html` を開きます。

```sh
npx http-server -p 8080 .
# → http://localhost:8080/
```

- **VS COM**: 自分のコマをドラッグで狙ってシュート（ドラッグの向き＝方向、長さ＝強さ）。先に4点取った方の勝ち。
- **2人対戦**: P1 → P2 の順にシュート。
- **観戦**: COM どうしを戦わせて、組み合わせの相性を確かめられます。
- 立ち位置（左・右）はラウンドごとに入れ替わります。

## 3つのパーツの役割

競技玩具研究所「ベイブレードＸ初弾構造レポート」による3層の役割分担を参考にしています。

| パーツ | 層 | 役割 | ゲームでの効き方 |
|---|---|---|---|
| ブレード | 上層 | 重さ・回転力・当たり方 | 質量・慣性モーメント・刃の弾く力・反発・回転方向。重いほど回転力は上がるが、中層を叩かれると慣性でロックが外れやすい |
| ラチェット | 中層 | 高さ・バーストの起点 | ブレードの高さ（＝どこで当たるか）。**バーストは中層に衝撃を受けたときだけ起こる**。突起の多い丸い外周ほど衝撃を受け流す |
| ビット | 下層 | 動き・バースト耐性・ダッシュ | 軸先の形で移動のしかたが決まる。**シャフトが太いほどバーストに強い**（攻撃軸＝太、持久・防御軸＝細）。ギアとクラッチでレール上の加速が決まる |

その結果、次のような組み合わせの駆け引きが生まれます。

- 低いラチェットの攻撃型は、刃が相手の中層に届くのでバーストを狙える
- 背の高い持久型は長く回れるが、低い相手に中層を叩かれやすい
- 重い防御ブレードは受けに強い一方、細いシャフトと組むとバーストしやすい
- ブレードどうしの当たりや壁への衝突ではバーストしないので、攻撃型が自分からバーストすることは少ない

## スタジアム

- 外周のギアレール（エクストリームライン）に噛むと、回転を速度に変えて加速する
- 奥のレールの切れ目（射出ポイント）で、スタジアムを縦断する向きに打ち出される
- 射出ポイントの対面（手前）がエクストリームゾーン（入口が高い）、その左右がオーバーゾーン（フェンスから滑らかに続く）
- スピン 1点 / オーバー 2点 / バースト 2点 / エクストリーム 3点

## 物理モデル（`src/physics.js`）

描画とは独立した決定的なシミュレーションです（600Hz 固定ステップ）。

- コマは「位置・速度・回転数・軸の傾き」を持つ剛体として近似
- 傾き＋斜面で床との接触点が軸からずれ、回転しながら床を蹴る → フラットは走り回り、ボールやニードルは中央に留まる
- 軸の傾きはジャイロ効果で歳差運動し、回転が落ちると不安定になって倒れる
- コマ同士の衝突は、接触点の表面速度（回転×半径）まで含めた撃力で解く。同じ向きの回転どうしは激しく弾き合い、逆回転どうしは回転を奪い合う
- 当たった高さで相手の中層への届き具合を計算し、回転と逆向きの角力積からロックの負荷を求めてバーストを判定する

## ファイル構成

```
index.html        画面
style.css
src/parts.js      パーツデータ（各パーツの役割はここで定義）
src/physics.js    物理演算・判定
src/render.js     Three.js による描画
src/audio.js      WebAudio の効果音
src/main.js       画面遷移・入力・ゲーム進行
tools/sim.mjs     ヘッドレスで総当たり対戦してバランスを確認（npm run sim）
vendor/           three.js r186（MIT）
```

パーツを追加・調整したら `npm run sim` で勝率と決着の内訳を確認できます。
